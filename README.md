# Artisan & Handmade E-commerce Website

## Overview

Artisan & Handmade E-commerce Website is a web-based platform designed to promote and sell handcrafted and eco-friendly products. The website provides a user-friendly shopping experience with product browsing, wishlist management, shopping cart functionality, user authentication, and product categorization.

## Features

* User Registration and Login
* Product Categories
* Product Search and Browsing
* Product Detail Pages
* Wishlist Functionality
* Shopping Cart
* Responsive User Interface
* Handmade and Eco-Friendly Product Showcase
* Database Integration using MySQL

## Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* PHP

### Database

* MySQL

### Development Environment

* XAMPP

## Project Structure

* Frontend pages for product browsing and shopping
* User authentication system
* Product management functionality
* Database connectivity using PHP and MySQL
* Responsive design for desktop and mobile devices

## Installation

1. Clone the repository.
2. Move the project folder to the XAMPP `htdocs` directory.
3. Import the provided SQL database into phpMyAdmin.
4. Start Apache and MySQL using XAMPP.
5. Open the project in a browser using localhost.

## Purpose

This project was developed as a college project to demonstrate web development skills, including frontend design, backend development, database integration, and e-commerce functionality.
